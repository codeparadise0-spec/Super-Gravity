# Web & Mobile App Visual References

Place reference screenshots and design mockups for **web applications, SaaS tools, interactive editors, and mobile web apps** in this directory.

### Guidelines for Antigravity:
* When building or brainstorming interactive app views, inspect images in this folder to understand clean sidebars, toolbar density, focused workspaces, and intuitive form flows.
* Ensure interactive controls have high touch target sizes ($\ge 44\times 44\text{px}$) and uncluttered action bars.
