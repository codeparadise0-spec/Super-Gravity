# Dashboard & Analytics Visual References

Place reference screenshots and design mockups for **analytics dashboards, admin portals, and data visualization interfaces** in this directory.

### Guidelines for Antigravity:
* When building or brainstorming dashboards, inspect images in this folder to understand clean metric card proportions, legible charts, and spacious tabular data presentation.
* Never overcrowd a dashboard with 20 tiny competing metric boxes. Prioritize 3-4 key high-impact KPI summary cards with clear typographic hierarchy.
