# Website Visual References

Place reference screenshots, wireframes, and design mockups for **websites, landing pages, marketing sites, and portfolio pages** in this directory.

### Guidelines for Antigravity:
* When building or brainstorming website layouts, inspect images in this folder to understand the target aesthetic, section flow, hero section spacing, and modern typography proportions.
* Avoid element crowding: prioritize generous vertical whitespace ($64\text{px}-96\text{px}$ between sections), clean hero headers, and minimal decorative noise.
