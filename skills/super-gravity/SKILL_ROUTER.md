# 🔀 Super Gravity Master Domain Redirection & Skill Router
### The Unconditional IF-THEN Execution Matrix for All Engineering Disciplines

This document is the **Mandatory Central Redirection Router** for the Super Gravity Engine. Whenever a task, user prompt, or subagent objective is initiated, the agent **MUST** classify the active domain(s) and immediately execute the mandatory skill sequence defined below.

```
═══════════════════════════════════════════════════════════════════════════════════════════════════════════
                              THE 7 MANDATORY DOMAIN REDIRECTION GATES
═══════════════════════════════════════════════════════════════════════════════════════════════════════════
  [GATE 1] Frontend & Visual UI       ──► Visual Benchmarks + Showcase + Tokens + Animations + A11y + QA
  [GATE 2] Backend & Distributed API  ──► Clean Architecture + Validation + Resilience + Security + Queues
  [GATE 3] React & Next.js Ecosystem  ──► App Router + Server Actions + Streaming + Zustand + Performance
  [GATE 4] Database & Caching Systems ──► Postgres Indexes + Transactions + Redis Patterns + Drizzle/Prisma
  [GATE 5] DevOps, Cloud & Security   ──► Docker Multi-Stage + K8s + Actions CI/CD + OTel + WAF + PKCE
  [GATE 6] Testing, QA & Verification ──► TDD Loop + Playwright E2E + DevTools Audits + Heap/Overflow QA
  [GATE 7] Architecture & Refactoring ──► ADR Design + System Review + Debt Triage + Safe Refactor
═══════════════════════════════════════════════════════════════════════════════════════════════════════════
```
